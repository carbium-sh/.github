# Carbium brand

- `carbium-mark.svg`: the Carbium mark on its dark background. Use this one on any surface.
- `carbium-mark-on-dark.svg`: the mark alone, for dark backgrounds only.
- `carbium-mark-400.png`: the mark on its dark background as a 400 by 400 PNG.

Colours: yellow `#FFBC00`, dark `#0F1217`, white `#FFFFFF`.
